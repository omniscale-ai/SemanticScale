# SH1b: Document-Level Split Validation

> Generated by `run_sh1b.py`

## Motivation

SH1 split spans randomly across train/val/test with label stratification only. Spans from the same paper could appear in both train and test, allowing the probe to exploit paper-level features (topic, style, vocabulary) rather than learning pure SLoD signal. This experiment re-runs the same pipeline with document-level (paper_id) grouping to quantify the inflation.

- **train**: 1109 papers, 26386 spans (macro=8621, meso=8935, micro=8830)
- **val**: 238 papers, 5639 spans (macro=1952, meso=1774, micro=1913)
- **test**: 238 papers, 5253 spans (macro=1853, meso=1717, micro=1683)
