# Data Dictionary

This document describes all data files used across SemanticScale experiments. Data is hosted on [Hugging Face](https://huggingface.co/datasets/anaderi/semantic-scale-data) and downloaded via `setup_data.py`.

## SH0 — Weak Label Bootstrap (155 MB)

| File | Format | Size | Description |
|---|---|---|---|
| `qasper_raw.jsonl` | JSONL | 66 MB | Raw QASPER dataset (1,585 NLP papers) |
| `qasper_slod_spans.jsonl` | JSONL | 62 MB | 83,135 text spans with heuristic SLoD labels (macro/meso/micro) |
| `qasper_slod_length_matched.jsonl` | JSONL | 28 MB | 37,278 length-matched spans (12,426 per class) |
| `label_distribution.png` | PNG | 84 KB | Visualization of label distribution |
| `validation_samples.jsonl` | JSONL | 47 KB | Sampled spans for manual validation |
| `validation_report.json` | JSON | 2 KB | Validation summary statistics |

**Provenance:** Generated by `sh0_weak_labels/scripts/run_labeling.py` from the HuggingFace `allenai/qasper` dataset using heuristic rules (section regex, position, content micro_score).

## SH1 — Linear Probe (315 MB)

| File/Dir | Format | Size | Description |
|---|---|---|---|
| `embeddings/` | NPZ | 311 MB | Embedding vectors for SciBERT, MiniLM, Specter2 (both full and length-matched) |
| `annotation_batch_*.json` | JSON | ~800 KB | 100 LLM annotation batches |
| `consensus_batch_*.json` | JSON | ~80 KB | 10 consensus annotation batches |
| `annotations_llm.json` | JSON | 148 KB | Aggregated LLM annotations |
| `splits.json` | JSON | 248 KB | Train/test split definitions |
| `splits_grouped.json` | JSON | 392 KB | Paper-grouped split definitions (no paper in both train and test) |
| `relabel/` | Dir | 2.3 MB | Relabeling data for annotation refinement |
| `results/` | Dir | 64 KB | Probe training results (accuracy, F1) |

**Provenance:** Embeddings generated by `sh1_linear_probe/src/embed_spans.py`. Annotations generated by LLM (Claude) for validation.

## SH5 — Jump Rate Analysis (16 MB)

| File | Format | Size | Description |
|---|---|---|---|
| `cot_traces/` | Dir | 8.7 MB | 2000 chain-of-thought reasoning traces (500 questions × 4 conditions) |
| `cot_slod_tags.jsonl` | JSONL | 2.7 MB | SLoD tags for each CoT step (heuristic) |
| `cot_slod_tags_llm.jsonl` | JSONL | 3.0 MB | SLoD tags via LLM classification |
| `answer_scores.jsonl` | JSONL | 286 KB | Token-F1 and attribution-F1 scores |

| `selected_questions.jsonl` | JSONL | 848 KB | Sampled QASPER questions |
| `results/` | Dir | 28 KB | Correlation results |

**Provenance:** CoT traces generated by Claude Haiku across 4 retrieval conditions (no_context, chunks_only, slod_weighted, slod_weighted_parent).

## SH5a/SH5c/SH5d — Extension Results

These contain intermediate and final results from reanalysis of SH5 data:

- **SH5a:** Transition matrices (NPZ), feature vectors (JSONL), clustering results
- **SH5c:** Alignment features (JSONL), correlation and subgroup analysis results
- **SH5d:** Step embeddings (NPZ), SLoD axis projections (NPZ), feature tables (Parquet/CSV)

**Provenance:** Derived from SH5 data by respective experiment scripts. No additional API calls needed.

## SH6 — LLM Pairwise SLoD

| File/Dir | Format | Size | Description |
|---|---|---|---|
| `{dataset}/{slug}/traces.jsonl` | JSONL | ~4 MB | Reasoning traces with outcome labels |
| `{dataset}/{slug}/chunk_rankings.jsonl` | JSONL | ~3.6 MB | Pairwise SLoD comparisons and Plackett-Luce ranks |
| `{dataset}/{slug}/trajectory_features.csv` | CSV | ~100 KB | Shape and structural features from SLoD trajectories |
| `anchor_validation/` | Dir | ~500 KB | Absolute SLoD calibration results |

**Provenance:** Traces generated via LLM inference or loaded from benchmarks (FrontierScience, ProcessBench, etc.). Pairwise judgments by Claude-3.5-Sonnet judge. Features computed via `05_analyze_failure_modes.py`.

## Cross-Experiment Data Dependencies

```
SH0 (labels) ──→ SH1 (embeddings) ──→ SH2 (steering vectors)
                                   ──→ SH3 (retrieval index)
                                   ──→ SH5d (SLoD axis)
SH5 (CoT traces) ──→ SH5a (transition matrices)
                  ──→ SH5c (alignment features)
                  ──→ SH5d (embedding projections)
SH3 (retrieval results) ──→ SH5c (context alignment)
SH5 (CoT traces) ──→ SH6 (comparison dataset)
```
